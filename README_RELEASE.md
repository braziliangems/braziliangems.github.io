# Brazilian Gems — site de revisão pública

O arquivo `index.html` e a pasta `assets/` devem ser enviados juntos para a raiz do repositório GitHub Pages.

- Idiomas: EN, PT, FR, ES, IT, 中文.
- Todas as notas do programa foram incorporadas aos seis idiomas.
- O botão QQ Music foi adicionado ao lado de Spotify, Apple Music, YouTube Music e Amazon Music.
- Os serviços de streaming e vídeos são *marcadores de posição*: nenhum link foi inventado.
- O site permanece editável após a publicação.
- A capa original e os arquivos de imagem foram preservados sem alterações.
- Para publicar, o repositório GitHub Pages deve ser público e ter Pages habilitado em Settings > Pages (Deploy from a branch, main / root).
- Recomenda-se revisão editorial final das traduções, em especial dos nomes chineses.
